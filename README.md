# Zenmoney CLI Application

> CLI-приложение на Go для синхронизации и анализа финансов ZenMoney.ru прямо из терминала.

`money-stat` загружает транзакции, счета, валюты и теги из [API ZenMoney](https://api.zenmoney.ru/v8/diff/) в локальную базу SQLite и строит отчёты по месяцам, годам и капиталу — без веб-интерфейса.

## Быстрый старт

```bash
git clone https://github.com/Simtel/go-money-stat.git
cd go-money-stat
go mod tidy
cp .env.example .env          # укажите ZENMONEY_TOKEN в .env
go build -o money-stat .
./money-stat sync             # загрузить данные в zenmoney.db
```

## Возможности

- **Синхронизация** — инкрементальная или полная загрузка данных из ZenMoney.
- **Транзакции** — списки за текущий и прошлый месяц с итогами.
- **Отчёты за год** — доходы, расходы и чистый результат по месяцам.
- **Динамика** — абсолютные и процентные изменения расходов/доходов.
- **Капитал** — помесячный баланс за год.
- **Счета** — балансы и валюты с итогами в рублях и долларах.

## Пример

```bash
$ ./money-stat accounts
 Итого в рублях   Итого в долларах   Общая сумма в рублях
 250000.00        1500.00            371695.00

 Счет            Баланс      Валюта
 Наличные        50000.00    RUB
 Карта           200000.00   RUB
 USD-счет        1500.00     USD
```

Запуск без аргументов открывает интерактивное меню выбора команды.
