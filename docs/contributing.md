# Участие в разработке

Участие приветствуется: создавайте Pull Request или Issues для обсуждения изменений.

## Рабочий процесс

1. Создайте ветку для функции:

   ```bash
   git checkout -b feature-name
   ```

2. Внесите изменения, проверьте тесты и линтер:

   ```bash
   go test ./...
   golangci-lint run
   ```

3. Зафиксируйте изменения:

   ```bash
   git commit -m "Описание ваших изменений"
   ```

4. Отправьте ветку:

   ```bash
   git push origin feature-name
   ```

5. Откройте Pull Request в `master`. CI автоматически запустит тесты и `golangci-lint`.

## Соглашения

- **Комментарии и сообщения** — на русском; **имена идентификаторов** — на английском.
- **Новые команды** добавляйте в подпакет `cmd/<имя>/`, не меняйте устаревшие файлы в корне `cmd/`.
- **Интерфейсы** описывайте в файле реализации; имя заканчивается на `Interface`.
- **DTO** — с суффиксом `Dto`.
- **Ошибки** оборачивайте через `fmt.Errorf("...: %w", err)`.
- **Миграции** выполняются автоматически через `AutoMigrate` в `dbinit.InitializeDB` — новые поля моделей подхватываются сами.
- **Не коммитьте** `.env` и `zenmoney.db`.
