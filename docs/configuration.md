# Конфигурация

## Переменные окружения

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `ZENMONEY_TOKEN` | Да | Токен доступа к API ZenMoney |

При старте приложение загружает `.env` через [godotenv](https://github.com/joho/godotenv) и проверяет наличие `ZENMONEY_TOKEN`. Если переменная пуста — приложение завершается с ошибкой:

```
ZENMONEY_TOKEN environment variable is required
```

Задавать токен можно двумя способами:

```bash
# 1. Через файл .env (рекомендуется)
cp .env.example .env
# отредактируйте .env

# 2. Через переменную окружения
ZENMONEY_TOKEN=ваш_токен ./money-stat accounts
```

## Файлы

| Файл | Назначение |
|------|------------|
| `.env` | Локальные переменные окружения (не коммитится) |
| `.env.example` | Шаблон с placeholder-значением |
| `zenmoney.db` | Локальная база SQLite (создаётся автоматически) |

`zenmoney.db` создаётся при первом запуске: GORM открывает SQLite с параметрами `cache=shared&mode=rwc`, после чего `dbinit.InitializeDB` выполняет `AutoMigrate` для всех моделей. База и `.env` перечислены в `.gitignore` — не коммитьте их.

## Валидация года

Команды `year`, `dynamics` и `capital` принимают год в диапазоне:

```
2021 ≤ год ≤ текущий год
```

Аргумент вне диапазона или не число приводит к ошибке `указан неверный год`.
