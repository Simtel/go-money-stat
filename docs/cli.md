# CLI-команды

Все команды строятся на [cobra](https://github.com/spf13/cobra). Запуск без аргументов открывает интерактивное меню выбора команды.

| Команда | Аргументы | Описание |
|---------|-----------|----------|
| `sync` | `-i`/`--incremental`, `-f`/`--full` | Синхронизация данных с ZenMoney |
| `months` | `current` \| `previous` | Транзакции за текущий или прошлый месяц |
| `year` | `<год>` | Отчёт доходов и расходов за год |
| `dynamics` | `<год>` | Помесячная динамика доходов/расходов |
| `capital` | `<год>` | Помесячный капитал за год |
| `accounts` | — | Список счетов с балансом и валютой |
| `migrate` | `init` | Инициализация/миграция базы данных |
| `list` | — | Список всех доступных команд |
| `menu` | — | Интерактивный выбор команды |

## sync

Синхронизирует финансовые данные с ZenMoney и сохраняет их в SQLite.

```bash
# Инкрементальная синхронизация (по умолчанию)
./money-stat sync
# явно
./money-stat sync --incremental

# Полная синхронизация: очистка и перезагрузка всех данных
./money-stat sync --full
```

Полная синхронизация (`--full`) очищает таблицы и загружает данные заново. Инкрементальная (`--incremental`) загружает только новые и изменённые записи с момента последней успешной синхронизации.

## months

Показывает транзакции за месяц с итоговой таблицей доходов/расходов. Аргумент обязателен.

```bash
./money-stat months current    # текущий месяц
./money-stat months previous   # прошлый месяц
```

## year

Отчёт по доходам и расходам за указанный год. Год должен быть в диапазоне от 2021 до текущего.

```bash
./money-stat year 2025
```

Результат — таблица по месяцам: доход, расход и чистый результат, с индикаторами роста/падения (↑/↓) относительно предыдущего месяца.

## dynamics

Помесячная динамика доходов и расходов с абсолютными и процентными изменениями.

```bash
./money-stat dynamics 2025
```

Таблица содержит: доход, Δ дохода, Δ% дохода, расход, Δ расхода, Δ% расхода и чистыми.

## capital

Помесячный капитал (сумма балансов) за указанный год.

```bash
./money-stat capital 2025
```

## accounts

Список счетов с балансом и валютой, а также итоги в рублях и долларах.

```bash
./money-stat accounts
```

## migrate

Управление миграциями базы данных (через GORM `AutoMigrate`).

```bash
./money-stat migrate init
```

## list

Печатает таблицу всех доступных команд с аргументами и примерами использования.

```bash
./money-stat list
```

## menu

Интерактивное меню выбора команды. Открывается автоматически при запуске без аргументов.

```bash
./money-stat menu
```
