# Быстрый старт

Установка и первый запуск `money-stat` — CLI-приложения для работы с финансами из [ZenMoney.ru](https://api.zenmoney.ru/v8/diff/).

## Требования

| Требование | Версия / значение |
|------------|-------------------|
| Go | 1.22 или выше |
| Токен ZenMoney | получить в настройках аккаунта ZenMoney |

Проверить версию Go:

```bash
go version
```

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Simtel/go-money-stat.git
   cd go-money-stat
   ```

2. Установите зависимости:

   ```bash
   go mod tidy
   ```

3. Создайте `.env` из шаблона и укажите токен:

   ```bash
   cp .env.example .env
   ```

   Откройте `.env` и заполните:

   ```env
   ZENMONEY_TOKEN=ваш_токен
   ```

4. Соберите бинарник:

   ```bash
   go build -o money-stat .
   ```

## Первый запуск

Запустите синхронизацию, чтобы загрузить данные в локальную базу `zenmoney.db`:

```bash
./money-stat sync
```

По умолчанию выполняется инкрементальная синхронизация — загружаются только новые и изменённые данные. Для полной перезагрузки используйте `--full`.

Проверьте результат — выведите счета:

```bash
./money-stat accounts
```

Вы должны увидеть таблицу со счетами, их балансом и валютой.
